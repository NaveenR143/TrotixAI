Generate a modern, ATS-compatible professional resume template.

TEMPLATE REQUIREMENTS:
1. The template must be fully ATS-safe and recruiter-friendly.
2. Use a clean single-column layout.
3. Avoid tables, multi-column layouts, icons, graphics, charts, images, or decorative elements.
4. Ensure the structure is optimized for Applicant Tracking Systems (ATS).
5. Use semantic HTML and clean CSS if generating web-based templates.
6. Maintain excellent readability and spacing.
7. Use professional typography and consistent formatting.
8. Ensure the template works well when exported to PDF.
9. Keep the design minimal, modern, and professional.
10. Prioritize clarity and scannability.

SECTION REQUIREMENTS:
Include the following sections in this exact order:

1. Header
   - Full Name
   - Professional Title
   - Phone Number
   - Email Address
   - LinkedIn
   - GitHub/Portfolio
   - Location

2. Professional Summary
   - 3-4 lines maximum
   - ATS-friendly wording
   - Professional and concise

3. Skills
   - Group skills logically
   - Examples:
     - Programming Languages
     - Frameworks & Libraries
     - Databases
     - Cloud & DevOps
     - Tools
     - Soft Skills

4. Professional Experience
   For each experience item include:
   - Job Title
   - Company Name
   - Location
   - Employment Dates
   - Bullet-point achievements
   - Technologies used
   - ATS-friendly formatting

5. Projects
   For each project include:
   - Project Name
   - Short Description
   - Technologies Used
   - Key Achievements or Impact
   - GitHub/Live Link (optional)

6. Education
   - Degree
   - Institution
   - Graduation Year
   - CGPA/Percentage (optional)

7. Certifications
   - Certification Name
   - Issuing Organization
   - Year

8. Languages
   - Spoken languages

DESIGN RULES:
1. Use strong visual hierarchy with section headings.
2. Maintain balanced white space.
3. Use readable font sizes.
4. Keep section spacing consistent.
5. Ensure content alignment is clean and professional.
6. Use subtle divider lines if necessary.
7. Avoid excessive colors.
8. Use black, dark gray, or navy as primary colors.
9. Make the template suitable for software engineers, data professionals, business professionals, and general corporate roles.

ATS COMPATIBILITY RULES:
1. Use standard section titles recognized by ATS systems.
2. Ensure all text remains machine-readable.
3. Avoid absolute positioning that may break parsing.
4. Avoid text embedded inside graphics.
5. Avoid hidden elements or decorative Unicode symbols.
6. Use proper heading hierarchy.
7. Ensure exported PDF text remains selectable.
8. Keep bullet formatting simple and standard.

OUTPUT REQUIREMENTS:
1. Generate a complete professional resume template.
2. Include realistic placeholder content examples.
3. Ensure the layout is visually polished and production-ready.
4. Keep the template responsive if generating HTML/CSS.
5. Make the final result suitable for immediate real-world use.
